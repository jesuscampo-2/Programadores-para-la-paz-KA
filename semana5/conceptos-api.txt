La ruta POST /reporte permite recibir información enviada por un usuario mediante una solicitud HTTP POST. En este caso recibe un mensaje y devuelve una respuesta en formato JSON indicando que el reporte fue recibido correctamente.

Esta ruta podría servir en una aplicación comunitaria para enviar reportes ciudadanos, alertas, denuncias o mensajes importantes desde una aplicación web o móvil hacia un servidor centralizado.
