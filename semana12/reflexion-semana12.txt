Durante este curso aprendí cómo utilizar diferentes herramientas tecnológicas para apoyar la participación ciudadana y la organización comunitaria. Comprendí la importancia de Git y GitHub para llevar el control de versiones, así como el uso de Node.js y Express para crear aplicaciones web. También aprendí sobre bases de datos, automatización y seguridad de la información. Entendí que una buena organización permite desarrollar soluciones más eficientes para las comunidades. Además, conocí cómo herramientas como Telegram y n8n ayudan a automatizar procesos y mejorar la comunicación. Todo esto fortalece el trabajo colaborativo y el desarrollo de proyectos tecnológicos con impacto social.
